## 二、必须记录的环境改动

### 1. 开启 BlueStacks ADB shell 访问（关键）

BlueStacks 默认 `bst.enable_adb_access="0"`，只允许白名单命令（`getprop`、`dumpsys`），
`input`、`wm`、`ls` 等全部返回 `error: closed`。

处理：

1. 完全退出 BlueStacks。
2. 备份 `C:\ProgramData\BlueStacks_nxt\bluestacks.conf`。
3. 将 `bst.enable_adb_access="0"` 改为 `"1"`。
4. 重启 BlueStacks。

等价 GUI 操作：BlueStacks 设置 → 高级 → 开启「Android Debug Bridge」。
改完后 `adb shell echo hi` 应正常输出。

> 本项目脚本会在 `doctor` 命令中检测该问题，并提示用户开启；不会静默失败。

### 2. 分辨率

```powershell
adb shell wm size 2400x1080
adb shell wm density 240
```

游戏强制竖屏，`screencap` 输出为 `1080x2400`。
`wm size` 是 Android 层覆盖，BlueStacks 重启后可能失效，脚本启动时需要重新检查/设置。

### 3. 游戏更新

Play Store 更新到 `29.1.1`。旧版 `29.0.6` 启动只显示「旧版本」弹窗，无法进入游戏。

## 三、v29.1.1 界面实测

截图见：

- `tests/frames/ingame_attack.png`
- `tests/frames/ingame_defense.png`
- `tests/frames/home_resume.png`
- `tests/frames/popup_gold_reward.png`

### 布局变化

- 升级面板标题条在约 y=1570–1645（1080×2400），比旧参考（y≈1629）更靠上。
- 卡片 2 列 × 3 行，但第三行被底部页签遮住一部分；完整购买第 5/6 张可能需要滚动。
- 标题条颜色：攻击=青蓝，防御=红/粉；可用于判断当前页签。
- 每张卡片：
  - 左侧属性名
  - 右侧数值框（带 `x5`/`x10` 角标）
  - 下方价格框
  - 已达上限的卡片显示灰色「上限」，价格框也变灰。

### 批量倍率

- 攻击页标题右侧显示 `x10`
- 防御页标题右侧显示 `x5`
- 说明每个页签有独立的批量购买倍率；点一次卡会买 5/10 级，价格也按倍数变化。
- v1 必须读取该倍率，或将其切到 1x，否则会超目标、超花费。

### 风险点

1. **误触内购**：点右上角购物车会弹出「金币奖励」，其中包含 `禁用广告 HK$78.00`。
   自动化必须识别弹窗并只点右上角 X，禁止在未知弹窗上盲点。
2. **点击命中异常**：测试中点击游戏速度 `+` 的区域却买到了「生命值再生」，
   说明 Unity UI 的点击热区与视觉位置可能存在偏移，或测试时弹窗层级干扰。
   后续必须用调试图 + 受控点击校准，不能直接沿用截图坐标。
3. 游戏有云存档确认、继续上局确认、旧版本提示、广告奖励弹窗等多种模态，
   状态机必须逐一识别，未知状态一律停止并截图。

## 四、最小化验证方法

```powershell
# 最小化（SW_MINIMIZE = 6）
ShowWindow(hwnd, 6)
# 恢复（SW_RESTORE = 9）
ShowWindow(hwnd, 9)
```

最小化后：

- `adb exec-out screencap -p` 仍能拿到实时画面。
- `adb shell input tap` 仍能操作游戏。
- 不需要移动 PC 鼠标，不需要窗口前台。

## 五、点击入口与等级校验（后续实测补充）

| 动作 | 位置 | 结果 |
| --- | --- | --- |
| 购买 | 卡片价格框中心（如右列 `(932, 1894)`） | 成功，价格 11.24K → 12.93K |
| 查看等级 | 卡片左侧属性名区域（如 `(632, 1843)`） | 弹出「当前等级 / 等级上限」 |
| 关闭等级弹窗 | 返回键 | 关闭弹窗；可能同时打开右侧菜单，不影响卡片点击 |
| 切页签 | 底部图标中心 `(110/354/606/850, 2320)` | 成功；点当前页签会收起面板，需先判断 |

**端到端实测**：

```text
防御/生命值再生 → 目标 110
真实等级 104，倍率 x5
购买 1: 15.88K → 17.88K，估算 109
购买 2: 17.88K → 20.02K，估算 114
弹窗校验：114（目标 110）通过
```

结论：v1 的「读等级 → 买 → 价格确认 → 等级校验」闭环成立。
