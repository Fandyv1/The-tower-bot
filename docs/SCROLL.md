# 滚动定位实现

日期：2026-10-17  
适配：The Tower 29.1.2 / 1080×2400

## 问题

升级面板一次只显示约 3 行（2 列），更深属性需要滚动。
实测滚动不是固定分页：同样 150px 的短滑，有时前进 1 行、有时 2 行。
因此不能按“页码 × 固定坐标”实现。

## 方案

1. **绝对槽位**：`slot` 是页签内从 0 开始的屏幕顺序，不再是“首屏 0–3”。
2. **回顶**：每步开始先向下滑几次，直到 OCR 看到该页签第 0 个属性名。
3. **逐步慢滑**：从顶部每次只滑 110px / 900ms，避免惯性跳行。
4. **OCR 找名字**：每一步在面板区域 OCR，精确匹配 `catalog.DISPLAY_CN` 里的中文名。
5. **推导坐标**：
   - 属性名中心 = 等级弹窗入口；
   - 购买点 = 同列价格框中心（属性名下方约 47px）。
6. **不盲点**：14 步内找不到属性名就保存截图并停止。

## 验证

- 攻击/射程（slot 4）：滚动 1 步找到。
- 攻击/速射几率（slot 8）：滚动 4 步找到；51 → 买 1 次 x10 → 弹窗校验 62。
- 功能/回复量（slot 8）：滚动 4 步找到。
- 两步策略 slot 8 → slot 0：第二步骤正确回顶，读到“伤害”。

## 限制

- 依赖属性名 OCR 可读；名字被遮挡或识别失败会停止。
- 极深槽位可能需要更多步进；当前上限 14。
- 滚动位置是运行中状态，不做跨进程持久化。
